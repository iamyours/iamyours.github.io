联系

这是一个个人项目，没有客服团队，也没有公开邮箱。最可靠的联系方式和公开讨论区都是 GitHub。

通过 GitHub Issues 联系

请到 iamyours/iamyours.github.io/issues 新建一个 issue。这是本站主要的反馈渠道，也方便其他人看到问题和后续进展。

Issues 是公开的，请不要在里面粘贴密码、身份证件、住址、电话号码或其他敏感信息。

GitHub 主页

如果你想先看看我在做什么，可以访问 github.com/iamyours。除了这个站点，那里也能看到其他公开仓库和项目。

可以报告什么

  • Bug：页面打不开、3D 场景报错、按钮没有反应、移动端布局异常等。
  • 反馈：对页面结构、说明文字、无障碍体验或游戏玩法的建议。
  • 版权问题：如果你认为某个页面、提示词或素材侵犯了你的权利，请说明涉及的作品、页面链接和你的诉求。
  • 隐私问题：对 localStorage、Google AdSense 或第三方资源有疑问，也可以开 issue。

让问题更容易定位

如果方便，请在 issue 里附上：出问题的页面网址、使用的浏览器和设备、复现步骤、实际看到的结果，以及截图（如果截图不含隐私信息）。3D 场景的问题还可以附上场景目录名，例如 3d/pelican/ 或 3d/earth-web/。

关于回复时间

这是业余时间维护的个人项目。我会尽量查看和回复，但无法保证响应时间，也不承诺每个请求都会被采纳。请保持耐心和礼貌。

版权与下架请求

如果你认为某段内容侵犯了你的版权，请通过 GitHub Issues 联系，并附上具体页面链接、涉及的作品或素材，以及你希望的处理方式。我会认真查看并尽快处理。

关于邮箱

本站不公布电子邮箱地址，也不通过邮件提供支持。请使用上面的 GitHub Issues 或 GitHub 主页。
