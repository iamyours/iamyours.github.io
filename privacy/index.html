隐私政策

最后更新： 2026-10-28

本政策说明 iamyours.github.io（下称「本站」）如何处理与访问者有关的信息。本站是一个静态的个人项目，不提供账号系统，也不运行自己的后端服务器。

1. 适用范围

本政策适用于本站的页面，包括首页游戏、/koi/、/3d/ 作品馆，以及关于、联系、隐私和使用条款等页面。站外链接（例如 GitHub、Google 广告设置）适用它们自己的隐私政策。

2. 不收集账号信息，也没有服务器端存储

本站没有注册、登录或用户资料功能，也不会把游戏进度或访问记录上传到我们自己的服务器。你不需要提供姓名、邮箱、电话或地址就可以浏览和使用本站。

3. 浏览器本地存储（localStorage）

本站使用浏览器的 localStorage 保存少量数据，这些数据留在此浏览器中：

  • 游戏存档：首页游戏的进度和设置（例如已解锁内容、资源数量等）。
  • 锦鲤池：/koi/ 页面的本地状态。
  • 语言偏好：键名 site-lang，用于记住你选择的界面语言。

这些数据只用于让你下次打开本站时恢复状态。你可以随时通过浏览器的站点数据或清除缓存功能删除它们；删除后，游戏进度可能无法恢复。

4. Google AdSense 与广告 Cookie

本站使用 Google AdSense（发布商 ID：ca-pub-5372826685368538，/ads.txt 中有相关记录）。第三方供应商（包括 Google）会使用 Cookie，根据用户此前对本站和/或其他网站的访问来投放广告。

Google 使用广告 Cookie，使其和合作伙伴能够根据用户对本站和/或其他网站的访问向用户投放广告。

你可以管理或退出个性化广告：

  • 在 Google 广告设置 中关闭个性化广告。
  • 在 Google 的广告技术说明 中了解 Google 如何使用广告 Cookie。
  • 在 aboutads.info/choices 退出部分第三方供应商的 Cookie。

游戏中的激励广告是可选的：只有你主动选择「看广告获得三叶草」时才会请求和播放广告；不选择时不会播放。即使选择观看，你也可以用上面的方式管理广告个性化。

广告由第三方提供，本站无法控制第三方 Cookie 的具体内容或保存时长。

5. 第三方 CDN 与字体

本站的部分页面从第三方加载开源库和资源：three.js 来自 unpkg.com 或 cdn.jsdelivr.net，部分页面使用 Google Fonts。当浏览器请求这些资源时，相应服务商会收到你的 IP 地址、User-Agent、请求路径等常规技术信息。这些请求受各自服务商的隐私政策约束。

6. 托管：GitHub Pages

本站通过 GitHub Pages 托管。GitHub 可能按照其政策记录访问日志（例如 IP 地址、请求时间、浏览器信息）。详情请参阅 GitHub 通用隐私声明。

7. 不使用分析或跟踪脚本

本站没有接入 Google Analytics、统计平台、广告跟踪像素或其他分析/跟踪脚本。

8. 儿童隐私

本站是面向一般访问者的个人项目，并非专门面向 13 岁以下儿童。本站不主动收集儿童的个人信息，也没有账号系统。如果你认为有儿童向本站提供了个人信息，请通过 GitHub Issues 联系，我会处理相关内容。

9. 政策变更

如果本站的功能、第三方服务或数据处理方式发生变化，本政策可能更新。更新后的版本会发布在本页，并修改页面顶部的「最后更新」日期。

10. 联系方式

对本政策有疑问，请通过 GitHub Issues 联系；也可以访问 github.com/iamyours。本站不公布电子邮箱。
