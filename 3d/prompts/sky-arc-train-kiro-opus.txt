用 three.js（r160，ES Module + import map，从 unpkg 或 jsDelivr 加载）编写一个单文件、自包含的 HTML 页面：「云海之上 · 星轨蒸汽列车」。一列太空蒸汽火车在云海上方沿一条水平巨型 C 形圆弧轨道行驶，途经一座维多利亚玻璃车站。全片是 25 秒一镜到底的电影级运镜，循环播放。所有贴图用 Canvas 或 shader 程序化生成，不加载任何外部图片、模型或字体。界面文字用中文。

一、坐标与轨道（必须严格遵守）
- 世界坐标 Y 轴朝上。轨道全程水平，铁轨高度 y = 0，整条弧线位于 XZ 平面内。
- 圆弧半径 R = 185，圆心在 (0, 0, -R)。用弧长 s 表示轨道上的位置，用 lat 表示横向偏移（正值指向圆弧外侧，也就是远离圆心的一侧）：
  θ = s / R
  x = (R + lat) · sinθ
  z = (R + lat) · cosθ - R
  物体朝向：rotation.y = θ（模型局部 +X 为前进方向，局部 +Z 为外侧）
- s = 0 在前景原点 (0, 0, 0)。轨道范围 s ∈ [-430, 440]，形成约 270° 的 C 形大弯：s 为负的一段从左后方弯过来，s 为正的一段向右后方的云海深处延伸。
- 写一个通用函数 arcPos(s, lat, y)。枕木、双钢轨、轨道下方的箱形梁、伸入云海的支撑塔柱、车站、列车全部用它摆放。不要用直线段去拼弯道。
- 轨道两外侧（lat = ±2）每隔 4 个单位放一个青白色自发光灯点。灯点沿轨道有流动的亮度脉冲；越靠近轨道尽头（s 最大的一端）越亮、越白，尽头本身是一团亮白色光晕。

二、宇宙天幕与云
- 天空用 shader 画深蓝夜空渐变（天顶接近黑蓝，地平线是稍亮的蓝），带星点。
- 太阳在画面左中方向，压得很低（方向约为 normalize(-0.82, 0.13, -0.56)）：一个耀眼的核心，外面是大范围暖色光晕。同一方向放一盏投射阴影的暖色平行光。
- 右上方挂一颗倾斜的巨型环状气态行星（土星，条纹贴图，带有卡西尼缝的环），旁边是一颗蓝灰色的伴星（月球）。
- 轨道下方 y ≈ -8 是一望无际的平铺云海，用 fbm 噪声 shader 做，要能流动翻滚，迎着太阳的方向有暖色前向散射，远处平滑融进地平线天色。可以再叠一些贴着云海表面的云团精灵。
- 巨型垂直积雨云柱（底部宽、腰部收窄、顶部像铁砧一样扩散，高约 200–270）共 4 座：
  · 左后方轨道拐弯起点附近 2 座，大约在 arcPos(-405, +70) 和 arcPos(-280, +95)；
  · 轨道尽头两侧各 1 座，大约在 arcPos(450, +62) 和 arcPos(450, -62)，列车最终驶向这两座云柱之间。
  · 云柱用软边精灵堆叠，朝太阳的一面亮、背光面偏蓝灰；半透明粒子每帧由远到近排序。

三、维多利亚拱形玻璃车站（s = -5 到 75）
- 中间是下沉式轨行区；两侧站台台面高 0.9，横向范围 |lat| 从 2.4 到 10.6，靠轨道一侧的站台边缘有一条黄色警示线。
- 每隔 5 个单位一榀黑色铸铁拱肋：半圆拱半径 10，拱脚高 4，内外双层拱圈之间用放射状腹杆连接，两端落在铸铁立柱上。拱顶上覆透明玻璃，加纵向檩条。列车驶入的那一端（s = -5）做扇形山墙，山墙中心要留出列车通过的净空。
- 站台台面是湿润的深色石砖：程序化生成砖块颜色贴图和粗糙度贴图，积水处粗糙度接近 0。要看得到列车、灯光、天空的倒影；可以用 CubeCamera 每隔几帧更新一次（更新时把站台本身隐藏），也可以用其他方案。
- 车站细节：成排的暖光吊灯、站台煤气灯柱、长椅、悬挂的站名牌（Canvas 文字「云海站」），再加 2–3 盏暖色点光源。

四、列车（机车 + 煤水车 + 3 节客车）
- 列车沿 s 增大的方向行驶（从左后方弯道驶来，穿过车站，向右后方远去）。机车位置 s_loco(t) = -250 + 24·t，t 为 0 到 25 秒。
- 每节车按 s_car = s_loco - offset 分别算位置和 rotation.y，offset 依次约为 0、7.7、18、30.8、43.6。这样整列车会在弯道上自然地逐节转弯，车与车之间用风挡折棚连接。
- 机车：孔雀蓝锅炉配黄铜箍、黄铜蒸汽包、黑色烟箱和烟囱。
  · 车头正面：烟箱门上有银色交叉（X 形）标志；顶部中央一盏大灯（SpotLight 加一个加色混合的体积光锥）；底部红色防撞梁上两盏前照灯和缓冲器。
  · 驾驶室：里面有暖橙色炉火光源，亮度会闪烁。
  · 3 对红色辐条动轮和 2 对导轮，按 角度 = -s / 半径 转动。
  · 联动杆、主连杆、十字头和活塞杆按真实的曲柄几何联动：两侧相位差 90°，十字头只在滑杆上沿水平方向往复。
- 煤水车：孔雀蓝车身配黄铜饰条，顶部堆满煤块。
- 客车厢：深色圆拱车顶、黄铜腰线、整面半透明玻璃车窗。透过玻璃要清楚看到车内的红色卡座沙发（相对而坐）、木桌和发光的暖色小台灯，每节车内放一盏暖色点光源。
- 烟囱持续喷出白色蒸汽烟雾（粒子由小变大、上升、逐渐变淡，在世界空间里自然拖在车后），汽缸处有向两侧喷出的短促蒸汽。页面一打开就要有完整的烟迹，可以预先模拟几秒。

五、一镜到底运镜（25 秒循环，各段之间用 smootherstep 和二次贝塞尔曲线平滑过渡，不能有跳变）
- 0–7 秒，广角远景：高机位俯瞰，相机约从 (105, 95, 200) 缓慢移到 (82, 78, 168)，看向约 (-50, -10, -120)，FOV 50。画面里要同时出现：从左侧积雨云柱旁弯过来的发光 C 形轨道、正在左侧弯道上喷着白烟的列车、右下前景的玻璃车站，以及天边的太阳和土星。
- 7–15 秒，推近进站：镜头从车站外侧压低，从两根立柱之间横向穿入，落到站台上，最终机位约在 arcPos(52.5, +4.3, 2.15)，FOV 放宽到约 60。先迎着弯道来车的方向（s 减小的方向）望去；列车亮着前大灯从弯道拐进站台，大约在第 12–13 秒贴着镜头呼啸而过，此时视线跟着掠过的车厢转动，看清飞转的连杆和通透的红座车厢，镜头可以有轻微震动。
- 15–25 秒，出站拉远尾随：镜头沿轨道上方飞出车站的另一端（高于车顶，不能穿过列车），平滑升到列车的左后上方（内侧，约 lat = -30，高 27，落后机车约 58 个单位），看向机车前方约 30 个单位处，俯瞰整列车沿圆弧驶向两座积雨云柱之间亮白发光的轨道尽头。
- 整个运镜路径不能穿过拱肋、立柱、灯柱和列车。循环衔接处用约 0.7 秒的黑场淡入淡出。

六、渲染与后期
- 使用 EffectComposer + RenderPass + UnrealBloomPass + OutputPass，色调映射用 ACESFilmic，开启 PCFSoft 阴影（阴影范围覆盖车站区域）。
- 只让太阳、灯点、车灯、炉火、台灯、轨道尽头这些高亮光源产生明显辉光，云和天空不能整体泛白。
  注意：three.js 的 ACES 会显著提亮暗部，夜空、雾色、云的基础颜色要压得足够低，曝光大约 0.8，保证画面整体是深蓝夜色。
- 用 scene.environment（例如用天空 shader 做 PMREM）给金属和玻璃提供反射。加和地平线同色的指数雾。
- 性能：静态零件按材质合并几何体（mergeGeometries），重复件用 InstancedMesh；粒子用一个自定义 shader 的 Points 对象（点大小随距离和 FOV 换算）。中端独显上要能流畅运行。

七、交互与界面
- 用 OrbitControls：用户一拖动就切换到自由视角，列车照常运行；按钮「自动运镜」可以切回脚本镜头，按钮「重播」从第 0 秒重新开始。
- 底部居中显示当前镜头段落名，底边一条细进度条。支持 URL 参数 ?t=秒数 直接跳到指定时刻。
- 窗口尺寸变化时自适应；在手机上布局不能溢出屏幕。

八、验收清单（输出前自查）
1. 轨道严格水平（所有轨道点 y = 0），位置和朝向都按上面的参数方程计算，车站和灯点都沿圆弧排布。
2. 5 节车分别计算朝向，过弯时逐节转向，车与车之间没有明显的断开或互相穿插。
3. 动轮转速和行驶速度一致（不打滑），连杆与曲柄销始终连在一起。
4. 第 12–13 秒列车在站台机位旁边掠过，玻璃里的红色座椅和台灯清晰可见，湿润站台上能看到倒影。
5. 第 20–25 秒画面里同时有：整列车、左右两座积雨云柱，以及中间亮白发光的轨道尽头。
6. 整体是深蓝夜色，太阳光晕在左、土星在右上；画面不过曝、不发灰。
7. 控制台没有报错，不依赖任何外部图片或模型。
