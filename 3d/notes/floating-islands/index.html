浮空岛世界

原始提示词

下面是从提示词文件中原样复制的正文。同一场景的各版本使用同一份提示词；为避免重复，这里只完整展示一次。

提示词文件 3d/prompts/floating-islands-web.txt
用 Three.js 在一个 HTML 文件中为我构建一个可以自由飞行探索的浮空岛世界，时间是黄金时刻（日落前的暖光）。
- 十几座大小不一的浮空岛悬在云海之上：顶部是起伏的草地和小树（程序化低多边形），底部是倒锥形的岩石，岩石用噪声做出层理和凹凸。
- 几座岛的边缘有瀑布倾泻而下，用滚动纹理的半透明水帘加底部的水雾粒子，水落入下方云海里消失。
- 岛上散落古代遗迹：断裂的石柱、拱门、残墙，带青苔色。
- 两三艘飞艇（气囊加吊舱）在薄雾中缓慢漂移，螺旋桨会转。
- 远处有层层的体积感云海和大气雾（距离雾加天空渐变 shader），低角度的太阳投下长长的阴影（开启阴影）。
- 操作：WASD 前后左右飞行，空格上升、Shift 下降，鼠标拖动转视角（点击画面后用 PointerLockControls），手机上用屏幕左下角虚拟摇杆加拖动。这个场景不用 OrbitControls。
- 左下角一行中文小字提示操作方法。
所有几何体和光照都程序化生成，不要使用图片。

【通用技术要求】
- 直接输出一个可在现代浏览器打开的完整单文件 HTML 代码（一个代码块，从 <!DOCTYPE html> 到 </html>，不要省略任何部分）。页面语言 zh-CN，标题用中文。
- 使用 Three.js r160，通过 importmap 从 CDN 固定版本加载："three": "https://unpkg.com/three@0.160.0/build/three.module.js"，"three/addons/": "https://unpkg.com/three@0.160.0/examples/jsm/"。除此之外不引用任何外部资源。
- 所有几何体、材质、贴图都用代码程序化生成（可用 Canvas/Shader 生成贴图），不要加载 glb/gltf/obj/fbx、图片或 SVG。
- 本场景是第一人称自由飞行，不使用 OrbitControls，按上面的操作说明实现。
- 画布全屏、响应式适配窗口大小变化和手机屏幕，devicePixelRatio 最多取 2，目标稳定 60FPS。
- 页面左上角放一个固定的链接「← 返回 3D 作品」，href="../"，半透明奶油色圆角小按钮样式。
- 在 </body> 前加上这一行（原样保留，用于展示提示词）：<script src="../prompt-panel.js" data-id="floating-islands-web"></script>
- 控制台不能有报错。不要问我任何问题，直接构建。

各版本的提示词文件只差用于展示提示词的 data-id 行和生成方式说明，场景描述正文相同。

对比观察

以下记录来自逐版阅读源码，只描述代码中能观察到的结构、动画与交互差异，不对模型作笼统排名。

DeepSeek 版用 12 个 Mesh 和 3 个 Group 搭出岛群与瀑布，PC 端 WASD + 指针锁定，移动端有摇杆和升降按钮，但没有 bloom，云层主要靠 shader 雾。Flash 版 18 个 Mesh，增加体积云、水面反射和更明显的黄金时刻雾，移动端摇杆与触摸转视角分开。Opus 5.5 版 16 个 Mesh 加 3 个 InstancedMesh，把植被和云实例化，控制收成「升/降」两个按钮和左下摇杆，代码只有 796 行。Web 版 25 个 Mesh、大量阴影调用，瀑布、水面、云和植被最完整，并同时支持 PointerLock、拖拽和移动端摇杆。Web 的瀑布和水面层次最多，Opus 5.5 的云和植被用实例化减少 draw call，Flash 的雾最浓，DeepSeek 的远景最干净。

这个场景是怎么做出来的

同一条提示词被分别交给下列模型。提示词要求生成一个可直接在现代浏览器打开的单文件 HTML，three.js 通过 CDN 的 import map 固定版本加载，几何体、材质和贴图全部由代码程序化生成，不能使用外部模型或图片。

生成结果作为静态页面发布在 GitHub Pages 上，没有构建步骤，也没有后端。页面里的尺寸、行数和技术标签是生成后从源码统计的；提示词原文公开在 3d/prompts/ 下，方便对照或复现。

发布前会检查页面能否加载、交互是否可用、移动端布局是否正常，必要时做站点层面的集成修正；场景内容本身由模型生成。下面列出每个版本使用时的模型说明。

  • Gemini 网页版（4 Argon） 同样的提示词，在 Gemini 网页上用 4 Argon（思考：高）生成。
  • Gemini 网页版（3.8 Flash） 同样的提示词，在 Gemini 网页上用 3.8 Flash 生成。
  • DeepSeek V4.1 Flash 同样的提示词，直接调用 ModelScope API 上的 DeepSeek-V4.1-Flash 生成。
  • Opus 5.5 同一提示词，用 Claude Opus 5.5 生成。
