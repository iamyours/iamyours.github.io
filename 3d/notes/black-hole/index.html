黑洞引力透镜

卡冈图雅式黑洞：纯黑事件视界、锐利光子环、引力透镜扭曲的星空和旋转吸积盘。场景测试模型对全屏后处理 shader、粒子盘、多普勒增亮和参数化观测台的理解。

原始提示词

下面是从提示词文件中原样复制的正文。同一场景的各版本使用同一份提示词；为避免重复，这里只完整展示一次。

提示词文件 3d/prompts/black-hole-web.txt
用 Three.js 在一个 HTML 文件中为我构建一个可交互的黑洞可视化，要有电影《星际穿越》里卡冈图雅那种震撼感。
- 黑洞本体：事件视界内部必须是纯黑（#000000），在透镜 shader 里光线落入视界半径就直接输出黑色，并且不参与 bloom 辉光；外面一圈明亮细锐的光子环。
- 引力透镜：用全屏后处理 ShaderMaterial 做光线弯曲，背景的程序化星空和银河在黑洞附近被扭曲、拉伸，形成爱因斯坦环。
- 吸积盘：用自定义 shader 绘制的倾斜发光圆盘，颜色从内圈的白热、橙黄渐变到外圈的暗红，带湍流噪声纹理并持续旋转；因为引力透镜，盘的背面要在黑洞上方和下方弯折出来可见；靠近我们这一侧因多普勒效应更亮。
- 环绕等离子体：几千个粒子（Points + 加法混合）沿螺旋轨道绕黑洞旋转、逐渐落入视界，带轻微拖尾。
- 加 UnrealBloomPass 辉光，整体色调电影感。
- 右上角一个小控制面板（自己用 HTML 写，不用外部 GUI 库），中文标签：黑洞质量（影响透镜强度）、吸积盘亮度、旋转速度、粒子数量、开关「透镜效果」。
- 拖动环绕视角、滚轮缩放；慢慢拉近时透镜扭曲越来越强。底部一行中文小字说明当前看到的现象。
不要使用图片。

- 使用 Three.js r160，通过 importmap 从 CDN 固定版本加载："three": "https://unpkg.com/three@0.160.0/build/three.module.js"，"three/addons/": "https://unpkg.com/three@0.160.0/examples/jsm/"。除此之外不引用任何外部资源。
- 所有几何体、材质、贴图都用代码程序化生成（可用 Canvas/Shader 生成贴图），不要加载 glb/gltf/obj/fbx、图片或 SVG。
- 使用 OrbitControls 支持拖动旋转、滚轮/双指缩放（第一人称玩法的场景除外，按场景说明）。
- 画布全屏、响应式适配窗口大小变化和手机屏幕，devicePixelRatio 最多取 2，目标稳定 60FPS。
- 页面左上角放一个固定的链接「← 返回 3D 作品」，href="../"，半透明奶油色圆角小按钮样式。
- 在 </body> 前加上这一行（原样保留，用于展示提示词）：<script src="../prompt-panel.js" data-id="black-hole-web"></script>

对比观察

以下记录来自逐版阅读源码，只描述代码中能观察到的结构、动画与交互差异，不对模型作笼统排名。

DeepSeek 版用 6000 个粒子、透镜 ShaderPass 和 bloom，配四条滑杆和透镜开关，几何体只有 3 个 Mesh，重点全在 shader 与粒子。Flash 版把吸积盘拆成更多 Mesh 和 4000 个粒子，控制台更偏「观测状态」文字反馈，视觉上更强调盘面层次。Opus 5.5 版代码最短（597 行），只用 1 个 Mesh 和 4000 个粒子，把黑洞、盘和透镜压进少量 shader，是最精简的一版。Web 版 1208 行、1 个 Mesh、3200 个粒子，控制台附有大段引力透镜/多普勒说明和多个观测状态文案，信息量最大。Web 的控制台还会根据黑洞质量、亮度和透镜开关切换观测文案，Opus 5.5 的面板可以折叠，DeepSeek 和 Flash 则始终展开。

这个场景是怎么做出来的

同一条提示词被分别交给下列模型。提示词要求生成一个可直接在现代浏览器打开的单文件 HTML，three.js 通过 CDN 的 import map 固定版本加载，几何体、材质和贴图全部由代码程序化生成，不能使用外部模型或图片。

生成结果作为静态页面发布在 GitHub Pages 上，没有构建步骤，也没有后端。页面里的尺寸、行数和技术标签是生成后从源码统计的；提示词原文公开在 3d/prompts/ 下，方便对照或复现。

发布前会检查页面能否加载、交互是否可用、移动端布局是否正常，必要时做站点层面的集成修正；场景内容本身由模型生成。下面列出每个版本使用时的模型说明。

  • Gemini 网页版（4 Argon） 同样的提示词，在 Gemini 网页上用 4 Argon（思考：高）生成。
  • Gemini 网页版（3.8 Flash） 同样的提示词，在 Gemini 网页上用 3.8 Flash 生成。
  • DeepSeek V4.1 Flash 同样的提示词，直接调用 ModelScope API 上的 DeepSeek-V4.1-Flash 生成。
  • Opus 5.5 同一提示词，用 Claude Opus 5.5 生成。
