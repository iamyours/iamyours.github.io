中秋月夜水榭

中秋月夜的水榭、满月、桂花雨、灯笼暖光和水面倒影。场景主要考验模型如何用程序化几何、粒子与反射拼出安静的夜景氛围，以及如何在不过度堆模型的情况下控制水面、辉光和视角。

CLI 版Gemini 网页版（4 Argon）DeepSeek V4.1 FlashOpus 5.5

原始提示词

下面是从提示词文件中原样复制的正文。同一场景的各版本使用同一份提示词；为避免重复，这里只完整展示一次。

提示词文件 3d/prompts/midautumn.txt
用 WebGL（Three.js r160）创作一个高精细度、写实浪漫风格的中秋月夜与水榭桂花微观角落场景，全部几何体、材质、贴图（使用 Canvas/Shader 过程生成）代码生成，目标稳定 60FPS，杜绝物体穿模。
视觉视角：全屏近距离平视与微俯瞰视角，聚焦于静谧水面上的古朴木质水榭亭台与盛开的金桂树。镜头支持平滑旋转与缩放。
场景主体布局：一座横跨水面的微型石拱桥、一座带翘角飞檐的古朴木质水榭、一株满树金黄且不断飘落花瓣的桂花树、水面上倒映着巨大满月的波光月影、几朵粉白荷花与荷叶，以及石桌上摆放的微型月饼与白瓷茶杯。
动态元件：夜空中一轮巨型满月，带陨石坑纹理与柔和金色月晕（Shader）；桂花树在夜风中轻微摇曳，金黄色桂花花瓣不断旋转飘落（粒子系统），落到水面后随涟漪漂浮；水面缓缓流动并有月亮和水榭的倒影（可用 three/addons 的 Reflector 或 Water 实现，注意性能）；水榭旁石头上一只白色玉兔，偶尔转动耳朵；池水中几条小金鱼在荷叶间游动。
光影与氛围：顶部清冷金白色月光与水榭下几盏红纸灯笼暖光共同照亮，形成冷暖对比；水面上缭绕一层薄薄的微光夜雾粒子。可使用 UnrealBloomPass 做柔和辉光。

【通用技术要求】
- 输出一个可直接在现代浏览器打开的完整单文件 HTML，写入当前目录的 index.html。页面语言 zh-CN，标题用中文。
- 使用 Three.js r160，通过 importmap 从 CDN 固定版本加载："three": "https://unpkg.com/three@0.160.0/build/three.module.js"，"three/addons/": "https://unpkg.com/three@0.160.0/examples/jsm/"。除此之外不引用任何外部资源。
- 所有几何体、材质、贴图都用代码程序化生成（可用 Canvas/Shader 生成贴图），不要加载 glb/gltf/obj/fbx、图片或 SVG。
- 使用 OrbitControls 支持拖动旋转、滚轮/双指缩放（第一人称玩法的场景除外，按场景说明）。
- 画布全屏、响应式适配窗口大小变化和手机屏幕，devicePixelRatio 最多取 2，目标稳定 60FPS。
- 页面左上角放一个固定的链接「← 返回 3D 作品」，href="../"，半透明奶油色圆角小按钮样式。
- 在 </body> 前加上这一行（原样保留，用于展示提示词）：<script src="../prompt-panel.js" data-id="midautumn"></script>
- 控制台不能有报错。不要问我任何问题，直接构建。

各版本的提示词文件只差用于展示提示词的 data-id 行和生成方式说明，场景描述正文相同。

对比观察

以下记录来自逐版阅读源码，只描述代码中能观察到的结构、动画与交互差异，不对模型作笼统排名。

CLI 版提供亭榭全景、月饼茶席、玉兔伴月、桂雨清涟四个机位，并用 76 个 Mesh、3 个 InstancedMesh 和 UnrealBloom 把灯笼、月亮与水面分开处理。Web 版没有机位按钮，但堆到 67 个 Mesh 和 24 个 Group，月亮、水面和花瓣各有独立 shader 与反射。DeepSeek 版 52 个 Mesh，水面用 Reflector，桂花和灯笼更依赖实例化。Opus 5.5 版把大量效果压进 多组 shader 代码，几何体数量仍接近 web，但代码行数只有 1337 行，是四版里最偏 shader 的一版。水面用 Reflector 接收月亮的倒影，灯笼的暖光与月光形成冷暖对比；四版都没有把相机做成第一人称，观者始终在一个略高的斜角上。

这个场景是怎么做出来的

同一条提示词被分别交给下列模型。提示词要求生成一个可直接在现代浏览器打开的单文件 HTML，three.js 通过 CDN 的 import map 固定版本加载，几何体、材质和贴图全部由代码程序化生成，不能使用外部模型或图片。

生成结果作为静态页面发布在 GitHub Pages 上，没有构建步骤，也没有后端。页面里的尺寸、行数和技术标签是生成后从源码统计的；提示词原文公开在 3d/prompts/ 下，方便对照或复现。

发布前会检查页面能否加载、交互是否可用、移动端布局是否正常，必要时做站点层面的集成修正；场景内容本身由模型生成。下面列出每个版本使用时的模型说明。

  • CLI 版 Gemini 通过 Antigravity CLI 生成。
  • Gemini 网页版（4 Argon） 同样的提示词，在 Gemini 网页上用 4 Argon（思考：高）生成。
  • DeepSeek V4.1 Flash 同样的提示词，直接调用 ModelScope API 上的 DeepSeek-V4.1-Flash 生成。
  • Opus 5.5 同一提示词，用 Claude Opus 5.5 生成。
