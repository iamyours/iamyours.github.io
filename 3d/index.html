关于这个 3D 作品馆

这里收录了 26 个可以实时运行的 three.js 场景。每个场景都有一条相同的文字提示词，分别交给 Gemini（Antigravity CLI）、Gemini 网页版 4 Argon / 3.8 Flash、DeepSeek V4.1 Flash 和 Claude Opus 5.5 等模型生成，再把结果并排放在一起，方便观察同一个任务上不同模型的取舍。点开任一场景的 「对比全部版本」，可以同时运行多个版本，拖动旋转、滚轮缩放，也能单独全屏；按分类进入 「播放合集」，则会按顺序连续播放该分类下的场景。页面按经典场景、体素世界、机械与载具、星球与宇宙、新场景五类整理，每个分类都有独立的合集入口。每个场景的提示词原文都公开在 3d/prompts/ 里，页面上也能展开查看和复制。所有场景都是模型生成的单文件 HTML，three.js 通过 CDN 的 import map 加载，没有构建步骤，也没有后端。想了解每个场景具体做了什么、各版本有哪些差别，可以打开下面的场景说明页。
